# HTML & CSS · Группа 17 — черновик программы на 14 уроков

Основа — программа «Месяц 1» на платформе (Подключение CSS → Box Model → Классы → Flexbox → …), растянутая на 14 уроков + тест на 15-м. Цель — к тесту ученик сам верстает лендинг по макету.

| № | Тема | Результат урока |
|---|---|---|
| 1 | Принципы HTML ✓ | понимает, что такое сайт, браузер, HTML/CSS/JS |
| 2 | Структура HTML ✓ | каркас: html, head, body, вложенность |
| 3 | Контент ✓ | h1–h6, p, ul/ol/li, a, img, пути к файлам |
| **4** | **Подключение CSS: цвет, фон, шрифт** | link, правило, селектор по тегу, color/background-color, font-*, наследование, каскад, DevTools |
| 5 | Блочная модель | div, span; margin, padding, border, width/height; блочные и строчные элементы |
| 6 | Классы и селекторы | class, несколько классов, потомок, :hover; сила селекторов |
| 7 | Семантика страницы | header, nav, main, section, footer; собираем каркас лендинга |
| 8 | Flexbox 1 | display: flex, justify-content, align-items, gap |
| 9 | Flexbox 2 · Header и Hero | меню, flex-wrap, первый экран сайта |
| 10 | Карточки и секции | border-radius, box-shadow, background-image, max-width + margin: auto |
| 11 | Формы | form, input, label, textarea, button; стили формы |
| 12 | Адаптив | %, rem, max-width, @media, мобильное меню |
| 13 | Позиционирование и детали | position, z-index, transition; иконки, шрифты Google Fonts |
| 14 | Мини-проект | лендинг по макету: от каркаса до адаптива |
| 15 | Тестирование | теория + вёрстка блока по макету |

Это предложение — порядок можно менять. Главное правило: каждый следующий урок использует всё, что было раньше, а практика собирает это в одну страницу.
