# HTML & CSS · Урок 4 · Подключение CSS: цвет, фон, шрифт

Интерактивная презентация для группы 17. Открыть: `index.html` (или задеплоенная версия).

## Слайды (23)
Разминка → «до/после» → 3 способа подключения → link → анатомия правила → селекторы → смеситель цвета → color/background по шагам → шрифты по шагам → наследование → каскад → DevTools → отладка → практика вместе → самостоятельная → словарь разработчика → шпаргалка (понятия + исключения) → домашка.

Дизайн: холст 16:9 (1920×1080) масштабируется под любой экран, тёмная тема по умолчанию (T — светлая). Клавиши: ← → — слайды, Пробел или ↓ — шаг демо, G — оглавление, N — заметки, T — тема, F — полный экран.
