# Урок 4 · Подключение CSS — шпаргалка

## Главные понятия

### 1. Подключение
```html
<head>
  <meta charset="UTF-8">
  <title>Сайт</title>
  <link rel="stylesheet" href="style.css">
</head>
```
- `rel="stylesheet"` — «это файл стилей». `href` — путь к файлу, как `src` у img.
- Файл в папке css → `href="css/style.css"`.
- Один файл стилей на весь сайт. `style="…"` у тегов и `<style>` — не используем.

### 2. Правило
```css
селектор {
  свойство: значение;
}
```
- Свойство и значение — через **двоеточие**, в конце — **точка с запятой**.
- Комментарий: `/* текст */`.

### 3. Селекторы
- По тегу: `p { }` — все абзацы страницы. Имя тега без `< >` и без точки.
- Группа: `h1, h2 { }` — одно правило на несколько тегов.

### 4. Цвет и фон
- `color` — цвет **текста**. `background-color` — цвет **фона**.
- Три записи одного цвета: `tomato` · `#ff6347` · `rgb(255, 99, 71)`.
- Текст и фон должны контрастировать.

### 5. Шрифт
| Свойство | Пример | Что делает |
|---|---|---|
| `font-family` | `Georgia, serif` | шрифт + запасной |
| `font-size` | `18px` | размер |
| `font-weight` | `bold` / `normal` | жирность |
| `font-style` | `italic` | курсив |
| `line-height` | `1.6` | высота строки |
| `text-align` | `center` | выравнивание |
| `text-decoration` | `none` | убрать подчёркивание |

### 6. Наследование и каскад
- Цвет и шрифт `body` наследуют все теги внутри.
- Два правила спорят за одно свойство → побеждает **нижнее**. Остальные свойства складываются.
- Стиль не работает? **F12 → Elements → Styles**.

## Исключения и ловушки
1. Ссылка не берёт цвет от body: у `a` свой синий цвет от браузера. Пишем `a { color: … }`.
2. Заголовки не берут размер и жирность от body: у `h1–h6` свои.
3. Нет `;` — ломается не только эта строка, но и следующая.
4. CSS не показывает ошибок: неверное свойство или значение просто пропускается. Ищем в DevTools.
5. Число и единица — слитно: `40px`, не `40 px`. У `line-height` можно без единиц: `1.6`.
6. Название шрифта с пробелом — в кавычках: `"Times New Roman"`.
7. Точка перед именем — это класс: `.h1` ≠ `h1`.
8. Файл в папке: `href="css/style.css"`. Имя должно совпасть буква в букву.
9. `style="…"` в HTML сильнее файла стилей — поэтому атрибут не используем.
10. Изменения не видно? Сохраните файл (Ctrl+S) и обновите страницу (F5).

## Словарь разработчика
| Термин | English | Как говорят | Пример |
|---|---|---|---|
| Таблица стилей | stylesheet | «стили», «цээска» | `<link rel="stylesheet">` |
| Правило | rule / ruleset | «правило» | `h1 { color: red; }` |
| Селектор | selector | «селектор» | `h1, h2` |
| Селектор типа | type selector | «по тегу» | `p { }` |
| Объявление | declaration | «строчка стиля» | `color: red;` |
| Свойство · значение | property · value | «проперти», «значение» | `font-size: 18px;` |
| Внешние · инлайн-стили | external · inline CSS | «вынести в файл», «инлайн» | `style="color: red;"` |
| Наследование | inheritance | «наследуется от родителя» | `body { color: navy; }` |
| Каскад | cascade · source order | «перебивает», «переопределить» | `p { } … p { }` |
| Стили браузера | user agent stylesheet | «дефолтные стили» | `a { color: blue; }` |
| Запасной шрифт | fallback font | «фолбэк» | `Georgia, serif` |
| Межстрочный интервал | line-height | «лайн-хайт», «интерлиньяж» | `line-height: 1.6;` |
| Контраст | contrast | «текст не читается» | `color: #fff;` |
| Инструменты разработчика | DevTools | «девтулзы», «инспектор» | `F12` |
