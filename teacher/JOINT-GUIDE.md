# Урок 4 · Совместная практика — сценарий для преподавателя

Файлы учеников: `materials/joint/index.html` и `style.css` — в них **нет кода**, только ТЗ в комментариях. Весь код пишем вместе с нуля под каждым пунктом.
Полное решение: `teacher/joint/`.
Время: 25 минут. На проекторе: VS Code слева, браузер справа.

Порядок на каждом шаге: прочитать ТЗ вслух → спросить группу «как будем делать?» → писать код → Ctrl+S → F5 → сверить с «Проверка».

| Шаг | Что пишем | Повторяем / новое | Мин |
|---|---|---|---|
| 1 | Каркас: `!` + Tab | урок 2 | 2 |
| 2 | h1, p, img, h2, ul, ol, a | урок 3 | 6 |
| 3 | `<link rel="stylesheet" href="style.css">` | **новое** | 2 |
| 4 | `body { background-color; color }` | **новое**: цвет | 2 |
| 5 | `body { font-family; line-height }` | **новое**: наследование | 3 |
| 6 | `h1, h2 { }` + `h1 { }` | **новое**: группа, правила складываются | 4 |
| 7 | `li { }` + `a { }` | **новое**: свой цвет у ссылки | 3 |
| 8 | DevTools + эксперимент с каскадом | **новое** | 3 |

---

## 1 · Каркас (2 мин)
В VS Code: `!` → Tab. Поменять title на «Кофейня «Утро»».
Спросить: «Зачем meta charset?» → без него могут сломаться русские буквы.

## 2 · Контент (6 мин)
Пишем по списку из ТЗ. Пусть ученики диктуют теги.
Спросить:
- «ul или ol для меню?» → ul, порядок не важен. «А для шагов заказа?» → ol.
- «Какой путь у картинки?» → `img/coffee.svg`, она лежит в папке img.
- «Что пишем в alt?» → что на картинке.

Показать результат: белая скучная страница. «Это HTML — ЧТО на странице. Сейчас добавим КАК».

## 3 · link (2 мин)
```html
<link rel="stylesheet" href="style.css">
```
В head под title. Спросить: «На что похож href?» → на src у картинки, это путь к файлу.
Подсказка: в VS Code `link` + Tab допишет `rel="stylesheet"`.

## 4 · Фон и текст (2 мин)
```css
body {
  background-color: #fdf6ec;
  color: #3b2f2f;
}
```
Ctrl+S в обоих файлах → F5. Фон кремовый — значит, файл подключён.
**Покажите ошибку специально:** переименуйте в `href="styles.css"` → фон белый. Верните.

## 5 · Шрифт (3 мин)
```css
  font-family: Arial, sans-serif;
  line-height: 1.6;
```
Спросить: «Мы писали только для body. Почему поменялись и заголовки?» → наследование.
«А ссылка какого цвета?» → синяя. Почему — шаг 7.

## 6 · Заголовки (4 мин)
```css
h1, h2 {
  font-family: Georgia, serif;
  color: #6f4e37;
}

h1 {
  font-size: 44px;
  text-align: center;
}
```
Спросить: «У h1 два правила — что он получит?» → всё из обоих: правила складываются.

## 7 · Списки и ссылки (3 мин)
```css
li {
  color: #b5651d;
  font-size: 18px;
}

a {
  color: #b5651d;
  font-weight: bold;
  text-decoration: none;
}
```
Главный вопрос: **«Почему ссылка не взяла цвет от body?»** → у `a` свой цвет от браузера, и он сильнее унаследованного.

## 8 · DevTools и каскад (3 мин)
1. F12 → Elements → клик по `<a>` → Styles. Найти: наше правило `a`, «user agent stylesheet» (перечёркнуто), «Inherited from body».
2. Снять галочку у `color` в правиле `a` → ссылка снова синяя.
3. В самый низ style.css: `h1 { color: tomato; }` → h1 красный. «Почему?» → ниже — побеждает. «А размер остался?» → да, правила складываются. Удалить строку.

**Покажите ошибку специально:** уберите `;` после `color: #6f4e37` → в DevTools свойство перечёркнуто, цвет и шрифт заголовков пропали.

## Бонус
`#fdf6ec` → `rgb(253, 246, 236)` → `linen`. Один цвет — три записи.

## Частые ошибки

| Ошибка | Что увидят |
|---|---|
| Не сохранили style.css | «ничего не работает» — Ctrl+S, потом F5 |
| `href="styles.css"` или файл в другой папке | стилей нет совсем |
| Нет `;` | пропадает это и следующее свойство |
| `font-color`, `text-color` | ничего; в DevTools жёлтый треугольник |
| `40 px` | размер не меняется |
| `.h1 { }` | ничего — точка означает класс |
| `<link>` в body или без `rel` | стили не подключились |
| Ждут, что ссылка станет цвета body | она синяя — нужно правило `a` |
